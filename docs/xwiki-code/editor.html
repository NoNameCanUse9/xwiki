XWiki Core Documentation

Welcome to the central repository for the XWiki API and internal structure. This document outlines the primary data flows.

## Installation

npm install @xwiki/core
npm run build:sys

## System Architecture

The architecture relies on a highly decoupled event bus that synchronizes documents across the network.

  • Event Bus: Central message broker for all document operations
  • Sync Engine: Handles real-time collaboration and conflict resolution
  • Storage Layer: Git-backed persistent storage with versioning
  • API Gateway: RESTful interface for external integrations

## Configuration

The system can be configured via environment variables or a xwiki.config.js file.

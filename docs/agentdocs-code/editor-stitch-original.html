# AgentDocs Core Documentation

Welcome to the central repository for the AgentDocs API and internal structure. This document outlines the primary data flows.

## Installation

npm install @agentdocs/core
npm run build:sys

## System Architecture

The architecture relies on a highly decoupled event bus that synchronizes documents across the network.

  • - Event Bus: Centralized message broker.
  • - Document Store: IndexedDB backed local persistence.
  • - Sync Engine: Handles conflict resolution and CRDT merging.
